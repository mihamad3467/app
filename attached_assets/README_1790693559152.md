# رفيقك الإيماني — نسخة محسّنة

بوت Telegram شامل للقرآن والأحاديث والأذكار ومواقيت الصلاة.

## أهم التحسينات

- مواقيت الصلاة تُحسب من موقع المستخدم.
- عرض المواقيت بنظام 12 ساعة مع `ص` و`م` بدل 24 ساعة.
- حفظ المنطقة الزمنية التي ترجعها خدمة AlAdhan مع موقع المستخدم.
- تنبيهات الأذان تُقارن بالوقت المحلي لكل مستخدم، وليس بتوقيت الرياض للجميع.
- تصفح السور والأحاديث عبر أزرار وصفحات.
- اختيار القارئ قبل تشغيل السورة.
- أزرار القراء تعرض اسم القارئ فقط بدون اسم الرواية الطويل.
- اختيار تسجيل مشهور واحد لكل قارئ بدل تكرار القارئ بصيغ متعددة.
- اختيار أوسع مصحف متاح للقارئ أولًا، حتى لا تختار نسخة جزئية لمجرد أنها
  تحمل اسمًا مشهورًا.
- عدم عرض أي تلاوة خارجية غير موثقة باسم عمير شميم: النسخة الخارجية القديمة
  لسورة الرحمن كانت تكرر من «رب المشرقين» إلى قرب النهاية، لذلك أزيلت
  التلاوات الخارجية غير الموثقة بدل عرض مقطع ناقص على أنه سورة كاملة.
- إضافة مصحف عمير شميم من أرشيفه العام، مع اختيار ملف سورة الرحمن
  الموسوم «كاملة» بدل ملفات «ما تيسر» أو المقاطع.
- شاشة جمعة مستقلة تحتوي على أدعية مأثورة وعدّاد يتحدث تلقائيًا.
- السور مرتبة بترتيب المصحف من السورة رقم 1 حتى السورة رقم 114.
- قائمة الصوتيات تعرض القراء المتاحين مع تسجيل مشهور واحد واضح لكل قارئ.
- أُضيف مصدر احتياطي لعبد الرحمن مسعد للسور المتاحة من المصدر الخارجي.
- أُضيف غيث سمرين مع سورة طه الكاملة المتاحة من أرشيف عام؛ لا تُعرض
  المقاطع القصيرة أو التجميعات على أنها سور كاملة.
- إرسال التلاوات يتم بتنزيل متدرّج إلى ملف مؤقت بدل تحميل السورة كاملة في
  الذاكرة، لتقليل تقطيع الملفات الطويلة مثل سورة الرحمن.
- أكثر من 250 حديثًا عربيًا محفوظة محليًا، وتظهر في شاشة الحديث النص والمصدر
  فقط بلا أرقام أو إيموجيات.
- أذكار، أيام للأجر، إعدادات، لوحة إدارة، وبث للمستخدمين.
- تنبيهات الأذان تعرض أسماء الصلوات بالعربية.
- أزرار القائمة الرئيسية معرّبة بلا إيموجيات زخرفية.
- اسم المستخدم الخاص بالمطور داخل قسم «مطور البوت»: `@dl_r7c`.
- إشعار للأدمن بعد دخول المستخدم ونجاح اشتراكه، يتضمن الاسم واليوزر والآيدي
  والنبذة وعدد مستخدمي البوت الإجمالي، مرة واحدة لكل مستخدم.

## ملاحظة مهمة عن التلاوات

المصدر الأساسي `mp3quran.net` يوفر ملفات كاملة للسور المدرجة في `surah_list`.
أما عمير شميم فمصدره الأساسي أرشيفه العام، وتظهر منه السور الكاملة
المعنونة كسور فقط، ومنها: الفاتحة، البقرة، الحجر، الفرقان، يس، ق، الذاريات،
الرحمن، الواقعة، الملك، الحاقة، الانفطار، البروج، الأعلى، الشمس، التين،
الزلزلة، الكافرون، والإخلاص. العناصر المسماة «ماتيسر» لا تظهر.
أما غيث سمرين فتظهر منه حاليًا سورة طه الكاملة فقط؛ الأرشيف العام المتاح
يحتوي أيضًا على مقاطع قصيرة وتجميعات، ولذلك لا تُضاف إلى قائمة السور.

## التشغيل

1. استخدم Python 3.11 أو أحدث.
2. ثبّت المتطلبات:

   ```bash
   python3 -m pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env` واملأ القيم.
4. شغّل:

   ```bash
   chmod +x run.sh
   ./run.sh
   ```

للنشر الذي يبحث تلقائيًا عن ملف `start.sh`، استخدم الملف المرفق
`start.sh`. ويجب أن تكون الملفات `main.py` و`start.sh` و`requirements.txt`
في جذر المشروع. في Replit يمكن وضع `BOT_TOKEN` و`ADMIN_ID` كـ Secrets،
ولا يلزم إنشاء `.env` عند استخدام Secrets.

لا ترفع ملف `.env` ولا تشارك توكن البوت.

## إعداد القناة

يجب أن يكون البوت مشرفًا في القناة الموجودة في `CHANNEL_USERNAME` حتى يعمل
التحقق الإجباري من الاشتراك.
